# 🕵️ Open Source Intelligence (OSINT) Guide


## Introduction

OSINT (Open Source Intelligence) involves gathering and analyzing publicly available information. Key areas include:

- **Introduction**: Basics of OSINT as a method for legal information collection.
- **Information Gathering**: Extracting data from public sources.
- **Mitre ATT&CK**: Framework for understanding cyber attack tactics and techniques. [Link](https://attack.mitre.org/)
- **OSINT**: Open-source intelligence techniques.
- **Data Leak**: Identifying leaked data like emails and passwords.
- **Photographs**: Analyzing metadata (e.g., GPS, date/time) in images.
- **Search Engine**: Using advanced search tools.
- **Deep Web & Dark Web**: Accessing hidden internet layers.
- **Privacy**: Protecting personal data during OSINT.
- **Email & Username**: Investigating user identities.
- **Data Base Leak**: Exploring leaked databases.
- **OSINT Test**: Practical application of OSINT methods.

Additional intelligence disciplines include MASINT, GEOINT, HUMINT, FININT, CYBINT, TECHINT, SIGINT, and OSINT.

## Frameworks and Models

- **SANS 497 OSINT Framework**: Educational course on OSINT frameworks. [Link](https://www.sans.org/cyber-security-courses/open-source-intelligence-gathering/)
- **Big Data**: Leveraging large datasets for analysis.
- **Social Media**: Primary source for personal and social data.
- **Cyber Kill Chain**: Model for describing cyber attack stages.
